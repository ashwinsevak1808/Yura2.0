# How to Write Product Descriptions

Since we don't have a rich text editor in the backend, we use **Special Characters** to tell the website how to format the text.

## The Magic Format
To show a nice list of details below your main description, simply copy and paste this structure.

### 1. The Separator
Use `— Product Details —` (or `-- Product Details --`) to separate your main story from the technical specs.

### 2. The Bullet Points
Use the bullet symbol `•` to start each new item in the list.

---

## 📋 Copy-Paste Template

```text
The Palash Kurti Top is crafted in soft, breathable rayon... (Your Main Description Here) ... styled effortlessly for everyday wear.

— Product Details —
• Fabric: 100% Cotton
• Color: Navy Blue
• Pattern: Printed
• Neckline: Round Neck
• Sleeves: 3/4th Sleeves
• Fit: Regular Fit
• Care: Machine Wash
```

---

## ⚡️ Quick Tips

1. **Bold Text**: If you write `Key: Value` (with a colon), the website will automatically make the "Key" bold.
   - Example: `• Fabric: Cotton` appears as **Fabric:** Cotton

2. **One Line is Fine**: You don't need to press "Enter". You can paste it all in one block, and the website will fix it.
   - Example Input: `Nice dress. — Product Details — • Fabric: Cotton • Color: Red`
   - Website Output:
     > Nice dress.
     >
     > **Product Details**
     > * **Fabric:** Cotton
     > * **Color:** Red

3. **Separators**: You can use any of these, they all work:
   - `— Product Details —` (Best)
   - `-- Product Details --`
   - `- Product Details -`
